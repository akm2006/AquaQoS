What is actually demonstrated

  • Official Aqua virtual balances remain independently accounted while real maker inventory is shared.
  • CAPACITY_GUARD rejects fills that would cross configured protected capacity.
  • Original benchmark Transfer logs, seeded demand and state deltas are checked; the separate rejection replay checks calldata, deployment identity and state deltas.
  • All current addresses are ephemeral local-EVM addresses; no public deployment has been made.

Reproduce the evidence

Trade-off: at eight strategies, low-contention swaps cost a median 210,099 gas with AquaQoS versus 113,715 without it. Guard rejections also cost more than raw settlement failures in the concentrated workload. These measurements use test tokens and fixed workloads.

pnpm install --frozen-lockfile --ignore-scripts
pnpm build
pnpm test
node scripts/check-benchmark.mjs
node scripts/check-rejections.mjs --self-test
pnpm test:transactions

These commands check retained benchmark evidence and execute the transaction checks. See the benchmark documentation to regenerate the comparative and rejection reports from clean commits.

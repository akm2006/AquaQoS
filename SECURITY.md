# Security policy

AquaQoS is an experimental, unaudited prototype. It is not production-ready and must not
be used to custody or protect assets of real value. The supported research target is the
latest tagged prototype and the current `main` branch.

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting for this repository. Include the affected commit, impact, required
preconditions, a minimal reproduction, and any suggested mitigation. If private reporting
is unavailable, open a public issue containing no exploit details and ask for a private
contact channel.

Receipt will be acknowledged when reasonably possible. No response time, remediation time,
safe-harbor program, or bug bounty is promised unless separately announced.

Known assumptions and accepted limitations are documented in
[`docs/SECURITY_REVIEW_SEPOLIA.md`](docs/SECURITY_REVIEW_SEPOLIA.md) and
[`docs/RELEASE_VERIFICATION.md`](docs/RELEASE_VERIFICATION.md).

## Event submission

Sources: [details](https://ethglobal.com/events/ethonline2026/info/details),
[start guide](https://ethglobal.com/events/ethonline2026/info/start),
[global rules](https://ethglobal.com/rules).

- [ ] Submit by **2026-09-13 12:00 EDT / 16:00 UTC / 21:30 IST**; no late submissions.
- [ ] Dashboard title, description and repository link; select 1inch (at most three partners).
- [ ] Classic work starts after event start; identify reused libraries/starters and all pre-existing work.
- [ ] Include repository/design evidence and complete specs, prompts and planning artifacts.
- [ ] Attribute AI-assisted code/files/assets; demonstrate meaningful human contribution.
- [ ] Video: 2–4 minutes, minimum 720p, working demo and human narration. No AI/TTS voice,
  mobile recording, sped-up footage or music/text substituting for narration.
- [ ] If finalist judging applies: four-minute demo plus three-minute Q&A.
- [ ] Each member accepted/staked; maximum five team members; complete dashboard check-ins.

Written organizer disclosure of pre-existing work is required by global rules. The brief
existed at takeover; its filesystem timestamp does not establish original creation time.
Eligibility is not certified until provenance and participant state are confirmed.

## Source-access distinction

Inspected Classic rules require repository evidence/access but did not establish a universal
public-source mandate. Public GitHub is our delivery target, subject to owner permission.
Upstream derivative-source/license obligations are a separate release gate; see
[third-party provenance](THIRD_PARTY.md). Do not label public-source policy as a quoted rule.

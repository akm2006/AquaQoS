# ETHOnline 2026 archive

This folder contains event-specific provenance, eligibility, and submission material. It is
retained for transparency and compliance, but it is not part of the AquaQoS runtime or product
documentation path.

- [Requirements](HACKATHON_REQUIREMENTS.md) records the official event and 1inch gates checked
  during the event.
- [Development provenance](AI_PROVENANCE.md) gives the concise AI-assistance and contribution
  disclosure.
- [Sanitized prompts](prompts/) retain the relevant specification and planning artifacts.
- [Manual actions](MANUAL_ACTIONS.md) and the [submission checklist](SUBMISSION_CHECKLIST.md)
  record owner-controlled event steps.

For the protocol itself, start at the repository [README](../../../README.md) or
[documentation index](../../README.md).
